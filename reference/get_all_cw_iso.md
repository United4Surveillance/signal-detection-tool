# function to get all time units between \`date_start\` and \`date_end\`

function to get all time units between \`date_start\` and \`date_end\`

## Usage

``` r
get_all_cw_iso(date_start, date_end, time_unit = "weekly")
```

## Arguments

- date_start:

  date object, starting date of sequence

- date_end:

  date object, ending date of sequence

- time_unit:

  a character specifying the time unit the case aggregation is performed
  on. Default is "weekly".
